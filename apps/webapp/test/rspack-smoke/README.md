# Rspack browser smoke tests

These tests serve the generated default internal Rspack build in `dist/internal` and the alternative public Rspack build in `dist/rspack-public` directly over HTTP. They do not use the Webpack development server or require credentials or backend services.

## Run locally

Build both variants and install Chromium once:

```bash
yarn nx run webapp:build
yarn nx run webapp:build-rspack-public
yarn playwright install chromium
yarn nx run webapp:smoke-rspack
```

The smoke target expects both builds, `apps/server/build/metadata/version.json`, and the built telemetry library to exist. It starts localhost-only static servers on ports 4173 and 4174, serves runtime configuration generated by `@wireapp/config`, and stops both servers when Playwright exits. It serves the telemetry embed from its normal production library output. The only backend responses served by the test server are `/api-version` and `/sso/settings`; API version 7 keeps this unauthenticated check on the email/password login landing UI.

## Coverage and limits

For each build, Chromium verifies the root HTML and its required entry scripts load, the application executes its unauthenticated redirect to `/auth`, the authentication application renders its login and account creation actions, and clicking Log in opens a usable email/password form. The tests fail on uncaught page errors and failed local requests or responses, including missing JavaScript chunks.

This is an unauthenticated browser smoke test. It does not exercise full authentication, MLS/Core Crypto WASM initialization, AVS calling, MediaPipe runtime behavior, service worker caching, or Electron integration.
